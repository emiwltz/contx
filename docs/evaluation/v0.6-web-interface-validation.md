**Status:** In progress; implementation present, dependency-backed verification
blocked

**Date:** 2026-08-02

## Scope implemented

- bounded inspection read models for overview, activity, events, corrections,
  patterns, candidates, final memory, local-model transformations, raw
  artifacts, processing runs, proposals, validations, and settings;
- FastAPI `/api/v1` contract with explicit Pydantic responses;
- literal-loopback `contx web` launch path;
- same-origin React/Vite/TypeScript SPA with dashboard, activity, patterns,
  memory, privacy, agent, and settings spaces;
- pause/resume and exclusion creation, enabling, disabling, and deletion through
  the durable collection-control service;
- direct active OptMem wake preview;
- append-only event and memory correction actions;
- explicit proposal adoption and rejection;
- immediate raw purge with exact confirmation and a distinct audited pipeline;
- full-data deletion with exact confirmation, live-daemon refusal, narrow-root
  checks, SQLite disposal, and API retirement;
- no raw artifact path or raw content endpoint.

## Deterministic evidence completed

The existing Python environment, which predates the new web dependencies, ran:

```text
.venv/bin/ruff check .
All checks passed!

.venv/bin/pytest -q --ignore=tests/integration/test_web_api.py
301 passed in 8.45s

.venv/bin/python -m compileall -q contx
exit 0
```

Focused tests prove:

- an unavailable required model produces a degraded overview without a
  fallback semantic path;
- inspection reports real persistent control, backlog, counts, raw usage, and
  raw expiry without returning a path;
- unexpired raw content is removed only by the explicit immediate-purge mode;
- full deletion leaves an adjacent unrelated file intact;
- full deletion refuses a live collector and unsafe nested roots;
- event summary correction uses the same append-only application service from
  CLI and API;
- all prior non-web behavior remains green.

The inspection test also exposed and now guards a persistence defect:
observations with optional `started_at` or `ended_at` values could be created
but failed when reconstructed from SQLite. The optional timestamp validator now
handles persisted `None` consistently.

## Verification blocked by the environment

FastAPI, Uvicorn, and httpx were not present in the existing virtual
environment. The npm cache also lacked a complete React/Vite/TypeScript
dependency set. Offline resolution failed as expected. Normal resolution then
failed at the sandbox DNS boundary.

The required privileged retry was rejected before execution because the
execution-credit quota is exhausted until 2026-08-09 09:38 Europe/Paris. The
same policy explicitly prohibited indirect or workaround installation. As a
result, these checks have **not** run yet:

- `uv lock` and environment synchronization with FastAPI/Uvicorn/httpx;
- `tests/integration/test_web_api.py`;
- full-package mypy including `contx.web.app`;
- `npm install`, frontend TypeScript checking, and Vite production build;
- verification that the wheel contains the static build;
- a live loopback server test and browser visual/accessibility QA.

J6 must remain in progress until those exact checks pass. The repository does
not currently claim a usable built web artifact.
