# First supervised metadata-only trial

Status: metadata resume/pause and automatic bounded stop observed; user-initiated
close with a live collector remains unverified.

## Authorized scope

Emi authorized the next short test after reviewing the sequence. Use the unchanged
installed signed application with a separate private temporary runtime root,
background collection enabled only in that root, initial indefinite pause,
window titles disabled and screenshots disabled. No LaunchAgent, model processing
or normal-data migration is part of this experiment.

A supervising process bounds the session to five minutes from launch. It checks
that the feature flags remain restricted, rejects any observation containing a
window title or image artifact, tracks collection state/counts, and stops owned
processes on completion or failure. It restores the test configuration to disabled
and verifies the normal runtime fingerprint and sealed release. Test data and
resource measurements remain private and outside Git.

## Sequence

1. Start the installed native host with the isolated root through LaunchServices.
2. Confirm a live owned collector, paused state and zero observations.
3. Emi resumes, switches between Finder and another chosen app, returns to CONTX,
   and pauses indefinitely.
4. Check application sequence/durations and that observations stop while paused.
5. Emi closes the window; verify exact host/child exit and final retained records.

No content captured by this trial is interpreted into events or memory. Successful
metadata collection does not establish focused-window capture, exclusion coverage,
long-duration resource acceptance, retention enforcement or pilot usefulness.

## Observations so far

The native host started its owned collector in pause with zero observations. Emi
confirmed completing the resume/application-switch/pause sequence. The supervisor
observed active state followed by indefinite pause. Ten records were retained:
nine active-application segments and one system-state segment. No window titles,
image artifact paths, events or model transformations were present. Two final
records were flushed on the next collection tick after pause, then counts stayed
constant. The last segment end was approximately 0.71 seconds after the durable
pause timestamp; this is the polling boundary, not proof of instantaneous stop.

Forty-five process samples were collected during the short session. Peak observed
RSS was about 113 MiB for the host and 125 MiB for the child. These brief samples
include startup/control work and are not a controlled-day CPU, energy or memory
acceptance baseline.

## Completion and remaining gate

The supervisor reached its five-minute deadline before receiving confirmation of
manual window close. It paused, stopped the exact trial child and host, disabled
the trial configuration and confirmed no collector lease, unchanged normal
runtime fingerprint and valid executable inventory. An independent process
check found neither the recorded host nor child PID alive. The trial ended with
ten records and no title/image fields. Private evidence is retained outside Git.

Resume, application segmentation, pause and bounded supervisory stop have live
evidence. Emi did not independently confirm the names of the selected apps, so
observed names alone are not a completed ground-truth comparison. The manual
red-close behavior with a live collector remains a separate short test before
advancing to titles or screenshots. No screenshot test or longer session started.
