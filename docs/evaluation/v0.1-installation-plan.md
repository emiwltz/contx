- Executable versions: `/Users/emi/Library/Application Support/CONTXRuntime/releases/<source-commit>/`.
- Create only missing CONTX-owned private directories with mode 0700.

  Do not relocate the temporary validated Python environment.

  Verify its complete signature and runtime inventory, then publish only when

## First installed launch

1. Confirm background collection is still disabled and no owned collector or
   processor is running. Abort if state differs; do not change user settings
   merely to make the smoke test pass.
2. Record a content-free fingerprint of existing runtime state.
3. Launch the final app normally. Confirm disabled state, visible window and Dock.
4. Have Emi close the window; confirm exact host exit and no collector lease.
5. Compare runtime fingerprints. Any unexpected mutation blocks advancement.

Permission attribution is a subsequent experiment. The current production host
has no permission-request command. Existing probe applications are diagnostic
artifacts and cannot prove attribution for a changed production executable.
Prepare the exact unchanged-host/child test before requesting privacy access;
do not grant access to generic Python as a substitute.

## Recovery

If the build or signature fails, leave the final application absent and remove
only the builder's identified unpublished staging state. Do not touch prior
releases or user data.

If the installed disabled launch fails, stop the exact owned host and verify
that its child has exited. Withdraw only this identified application to its
private staging location and unregister that app path if it was registered.
Retain its sealed runtime for diagnosis. Preserve all CONTX configuration,
databases, caches, logs, models and previous releases. No privacy permission
reset is needed for this installation-only step.

Before any future upgrade, preserve the prior signed application together with
its referenced version, stop owned processes, and verify the selected pair.
An executable rollback must not imply a user-data rollback or migration.
